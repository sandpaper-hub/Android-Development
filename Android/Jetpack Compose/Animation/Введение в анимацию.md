В **Jetpack Compose** анимации встроены прямо в UI-систему и работают **декларативно** — то есть ты не изменяешь напрямую свойства объекта во времени, а задаёшь, _как они должны меняться_, а Compose сам отрисует плавный переход.

---

## 1. Виды анимаций в Jetpack Compose

В Compose можно выделить несколько основных подходов:

|Вид анимации|Когда использовать|Пример|
|---|---|---|
|**Value-based анимация** (`animate*AsState`)|Для плавного изменения одного значения|Плавное изменение размера, цвета, прозрачности|
|**Transition API** (`updateTransition`)|Когда несколько свойств зависят от одного состояния|Кнопка, меняющая и цвет, и размер при нажатии|
|**AnimatedVisibility**|Для появления/исчезновения элементов|Показывать панель, когда нужно|
|**InfiniteTransition**|Для бесконечных циклов|Пульсация кнопки, мерцание индикатора|
|**Gesture-driven анимации** (`Animatable`, `DecayAnimation`)|Для физически правдоподобных движений|Свайпы, отскоки, fling-эффекты|

## 2. Простая анимация с `animate*AsState`
[[animateDpAsState]] - анимация dp
Если нужно анимировать одно значение — например, цвет кнопки при клике:

```kotlin
@Composable
fun ColorAnimationExample() {
    var isRed by remember { mutableStateOf(true) }
    val color by animateColorAsState(
        targetValue = if (isRed) Color.Red else Color.Blue,
        animationSpec = tween(durationMillis = 1000)
    )

    Box(
        modifier = Modifier
            .size(100.dp)
            .background(color)
            .clickable { isRed = !isRed }
    )
}
```

🔹 `animationSpec` определяет тип анимации:

- `tween()` — обычная линейная/с плавным замедлением;
    
- `spring()` — пружинная анимация;
    
- `keyframes()` — пошаговая анимация.

## 3. Анимация нескольких свойств с `updateTransition`

Когда меняются несколько параметров при одном переключении состояния:

```kotlin
@Composable
fun TransitionExample() {
    var expanded by remember { mutableStateOf(false) }
    val transition = updateTransition(expanded, label = "boxTransition")

    val size by transition.animateDp(label = "size") {
        if (it) 200.dp else 100.dp
    }
    val color by transition.animateColor(label = "color") {
        if (it) Color.Green else Color.Gray
    }

    Box(
        modifier = Modifier
            .size(size)
            .background(color)
            .clickable { expanded = !expanded }
    )
}
```

## 4. Анимация появления/исчезновения — `AnimatedVisibility`

```kotlin
@Composable
fun VisibilityExample() {
    var visible by remember { mutableStateOf(true) }

    Column {
        Button(onClick = { visible = !visible }) {
            Text("Toggle")
        }
        AnimatedVisibility(visible = visible) {
            Box(
                modifier = Modifier
                    .size(100.dp)
                    .background(Color.Magenta)
            )
        }
    }
}
```

Можно кастомизировать вход/выход:

```kotlin
enter = fadeIn() + slideInVertically(),
exit = fadeOut() + shrinkVertically()
```

## 5. Бесконечная анимация — `rememberInfiniteTransition`

```kotlin
@Composable
fun InfiniteAnimationExample() {
    val infiniteTransition = rememberInfiniteTransition()
    val alpha by infiniteTransition.animateFloat(
        initialValue = 0.5f,
        targetValue = 1f,
        animationSpec = infiniteRepeatable(
            animation = tween(1000, easing = LinearEasing),
            repeatMode = RepeatMode.Reverse
        )
    )

    Box(
        modifier = Modifier
            .size(100.dp)
            .graphicsLayer(alpha = alpha)
            .background(Color.Cyan)
    )
}
```

## 6. `Animatable` — для жестов и ручного управления

```kotlin
@Composable
fun AnimatableExample() {
    val offsetX = remember { Animatable(0f) }
    Box(
        Modifier
            .offset { IntOffset(offsetX.value.roundToInt(), 0) }
            .size(100.dp)
            .background(Color.Yellow)
            .clickable {
                // Запустить анимацию вручную
                LaunchedEffect(Unit) {
                    offsetX.animateTo(
                        targetValue = 300f,
                        animationSpec = spring(dampingRatio = 0.5f)
                    )
                }
            }
    )
}
```

`Animatable` даёт полный контроль: можно останавливать, изменять скорость, применять физические модели (`DecayAnimation`).

## 7. Как это связано с производительностью

- Compose анимации оптимизированы под **GPU** и работают в отдельном кадре UI.
    
- Лучше анимировать простые значения (цвет, размер, смещение) вместо сложных перерисовок.
    
- Если анимация рендерит тяжёлый UI — использовать `LaunchedEffect` и оптимизировать отрисовку.
