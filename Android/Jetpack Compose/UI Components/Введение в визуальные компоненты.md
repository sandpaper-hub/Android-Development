В Jetpack Compose существует огромное количество встроенных компоновщиков для отображения текста, изображений, кнопок, полей ввода и многого другого.

#### **Обзор Визуальных Компонентов**

Визуальные компоненты — это строительные блоки пользовательского интерфейса. Они отвечают за отображение информации и взаимодействие с пользователем. В Compose каждый такой компонент является **Composable-функцией**.

**Ключевые принципы:**

- **Декларативность:** Вы описываете, _что_ должно быть на экране, а не _как_ это нарисовать.
- **Композиция:** Сложные UI создаются путем комбинирования более простых компоновщиков.
- **Модификаторы:** Позволяют настраивать внешний вид и поведение любого компоновщика.
