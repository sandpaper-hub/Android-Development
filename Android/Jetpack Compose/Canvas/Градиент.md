В контексте **Canvas / DrawScope** в Compose под градиентом понимается использование **Brush** вместо простого цвета.

---

## **🔹 Что такое** 

## **Brush**

  

Brush — это объект, который описывает **как именно заполнять фигуру цветом**.

Он может быть:

- **SolidColor** → просто один цвет (аналог Color.Red).
    
- **LinearGradient** → линейный градиент.
    
- **RadialGradient** → радиальный градиент (из центра в стороны).
    
- **SweepGradient** → круговой градиент (по окружности).
    

  

👉 Все они поддерживаются в Canvas, через методы drawRect, drawCircle, drawPath, drawArc и т.д.

---

## **🔹 Основные типы градиентов**

  

### **1. Линейный градиент**

  

Плавный переход между цветами по прямой.

```kotlin
@Composable
fun LinearGradientRect() {
    Canvas(modifier = Modifier.size(200.dp)) {
        drawRect(
            brush = Brush.linearGradient(
                colors = listOf(Color.Red, Color.Blue),
                start = Offset(0f, 0f),
                end = Offset(size.width, size.height)
            ),
            size = size
        )
    }
}
```

👉 Переход от красного в верхнем левом углу к синему в правом нижнем.

---

### **2. Радиальный градиент**

  

Цвет расходится от центра (или заданной точки) по радиусу.

```kotlin
@Composable
fun RadialGradientCircle() {
    Canvas(modifier = Modifier.size(200.dp)) {
        drawCircle(
            brush = Brush.radialGradient(
                colors = listOf(Color.Yellow, Color.Red),
                center = center,
                radius = size.minDimension / 2
            )
        )
    }
}
```

👉 Жёлтый в центре, плавный переход в красный по краям.

---

### **3. Sweep (угловой, круговой) градиент**

  

Цвет распределяется по окружности (как радуга или “пирог”).

```kotlin
@Composable
fun SweepGradientArc() {
    Canvas(modifier = Modifier.size(200.dp)) {
        drawCircle(
            brush = Brush.sweepGradient(
                colors = listOf(Color.Magenta, Color.Cyan, Color.Green, Color.Magenta),
                center = center
            )
        )
    }
}
```

👉 Получится круг с “радугой” по углам.

---

## **🔹 Параметры градиента**

- **colors** → список цветов.
    
- **colorStops** → пара (позиция от 0f до 1f, цвет). Позволяет точно управлять где будет переход.
    
- **start / end** (в linearGradient) → направление.
    
- **center / radius** (в radialGradient) → центр и радиус.
    
- **tileMode** → что делать, если область больше градиента:
    
    - Clamp (по умолчанию) → последний цвет продолжается.
        
    - Repeat → градиент повторяется.
        
    - Mirror → градиент отражается.
        
    

---

## **🔹 Примеры использования в Canvas**

  

### **Градиентный прогресс-бар (дуга)**

```kotlin
@Composable
fun GradientArc(progress: Float) {
    Canvas(modifier = Modifier.size(200.dp)) {
        drawArc(
            brush = Brush.sweepGradient(
                colors = listOf(Color.Green, Color.Yellow, Color.Red)
            ),
            startAngle = -90f,
            sweepAngle = 360f * progress,
            useCenter = false,
            style = Stroke(width = 20f, cap = StrokeCap.Round)
        )
    }
}
```

👉 Круговой индикатор, где цвет прогресса плавно меняется.

---

## **🔹 Где используется**

- Красивые **фоны** (квадраты, круги, градиентные фигуры).
    
- **Индикаторы прогресса** (например, кольцо с переходом от зелёного к красному).
    
- **Диаграммы** (pie chart с градиентными сегментами).
    
- **Игры и визуализации** (эффекты сияния, вспышки).
    
- **Текстуры** (волны, световые эффекты).
    

---

📌 Итог:

- В Canvas вместо color можно передавать brush.
    
- Есть три основных градиента: linearGradient, radialGradient, sweepGradient.
    
- Они дают мощный способ добавить глубину и “живость” к фигурам.
