В `Canvas` и `DrawScope` трансформации — это то, что позволяет **временно изменить систему координат**, чтобы поворачивать, масштабировать и перемещать всё, что рисуется внутри блока.

---

## 🔹 Основные трансформации

В `DrawScope` есть специальные функции:

```kotlin
rotate(degrees: Float, pivot: Offset = center) { ... }
scale(scaleX: Float, scaleY: Float, pivot: Offset = center) { ... }
translate(left: Float = 0f, top: Float = 0f) { ... }
withTransform(transformBlock: TransformScope.() -> Unit) { ... }
```

Все они работают **только внутри своего блока** → после выхода координаты снова обычные.  
То есть это как временная "матрица преобразования" для рисования.

---

## 🔹 Подробно про каждую

### 1. `rotate`

Поворачивает систему координат.

- `degrees` — угол в градусах (по часовой стрелке).
    
- `pivot` — точка, относительно которой поворот.
    

```kotlin
Canvas(modifier = Modifier.size(200.dp)) {
    rotate(degrees = 45f) {
        drawRect(Color.Red, size = size / 2f)
    }
}
```

👉 Красный квадрат будет повернут на 45°.

---

### 2. `scale`

Изменяет масштаб по осям X и Y.

- `scaleX = 2f` → растянет по горизонтали в 2 раза.
    
- `scaleY = 0.5f` → сожмёт по вертикали в 2 раза.
    
- Можно задать `pivot` (по умолчанию центр Canvas).
    

```kotlin
Canvas(modifier = Modifier.size(200.dp)) {
    scale(scaleX = 1.5f, scaleY = 0.5f) {
        drawCircle(Color.Blue, radius = 80f, center = center)
    }
}
```

👉 Синий круг станет эллипсом.

---

### 3. `translate`

Сдвигает систему координат.

- `left` — сдвиг по X.
    
- `top` — сдвиг по Y.
    

```kotlin
Canvas(modifier = Modifier.size(200.dp)) {
    translate(left = 50f, top = 80f) {
        drawRect(Color.Green, size = Size(60f, 60f))
    }
}
```

👉 Зелёный квадрат будет нарисован со смещением.

---

### 4. `withTransform`

Даёт полный контроль над матрицей преобразования.  
Можно комбинировать: поворот + масштаб + перенос.

```kotlin
Canvas(modifier = Modifier.size(200.dp)) {
    withTransform({
        translate(100f, 50f)
        rotate(30f)
        scale(1.2f, 1.2f)
    }) {
        drawRect(Color.Magenta, size = Size(80f, 80f))
    }
}
```

👉 Нарисуется квадрат, сначала сдвинутый, потом повернутый, потом увеличенный.

---

## 🔹 Важные моменты

1. **Трансформации локальны** — они действуют только внутри блока.
    
2. **Порядок важен** — `rotate → translate` ≠ `translate → rotate`.
    
3. Можно вкладывать блоки трансформаций:
    
    ```kotlin
    rotate(45f) {
        translate(50f, 0f) {
            drawCircle(Color.Red, radius = 40f)
        }
    }
    ```
    
    👉 Сначала поворот, потом сдвиг.
    

---

## 🔹 Где это нужно

- Рисование **повторяющихся элементов** под углом (например, циферблат часов).
    
- Создание **симметричных фигур** (звёзды, снежинки).
    
- Анимации (вращающиеся стрелки, бегущие элементы).
    
- Графики (подписи осей под углом).
    
- Игры (вращение персонажей, перемещение объектов).
    

---

📌 Итог:

- `rotate` → поворот.
    
- `scale` → масштабирование.
    
- `translate` → перенос.
    
- `withTransform` → комбинация трансформаций.
    
- Всё это работает **временно внутри блока** → удобно для локального изменения рисунка.
